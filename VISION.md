# Vision

**Bolt is not trying to replace React.**

**Bolt is an abstraction layer over React.**

Modern web development has become increasingly complex. Developers spend more time wiring together state management libraries, routers, bundlers, and API clients than actually building features. 

The vision of Bolt is to separate **intent** from **implementation**.

- **Developers write intent:** What should the UI look like? What happens when a button is clicked?
- **The compiler generates implementation:** How is state managed? How does the VDOM update? How are HTTP requests dispatched?

By compiling to standard React, Bolt apps remain fully compatible with the massive React ecosystem, but the developer experience is elevated to focus entirely on the product logic.

Code should be human-readable, maintainable, and fast to write. That is Bolt.
