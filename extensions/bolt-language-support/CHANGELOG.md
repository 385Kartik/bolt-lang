# Changelog

## 1.6.0
- Plain-word requests: colors for `header`, snippets `submit`, `loginreq`, and simpler `fetchheaders` / `patch`

## 1.5.0
- Colors for `patch`, `headers`, `respond` and the `http_get` / `http_post` / `http_put` / `http_patch` / `http_delete` helpers
- Four new snippets: `fetchheaders`, `patch`, `httpget`, `respond`

## 1.4.0
- Colors for login helpers (`hash_password`, `check_password`, `sign_token`, `need_login`) and the `hidden` field option
- Snippet for a login endpoint

## 1.3.0
- `endpoint` blocks: colors, helper words (`reply`, `contains`, ...), snippets

## 1.2.0
- Format Document (Shift+Alt+F) using `bolt fmt`

## 1.1.0
- New syntax colors (`styles:`, `layout:`, `slot`, `resource`, `use`, `design system:`, `styled as:` class lists)
- Snippets, suggestions (styles, components, pages, files)
- Problems in the editor from `bolt check`
